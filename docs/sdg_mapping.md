# UN Sustainable Development Goal (SDG) Mapping

## Primary: SDG 9 - Industry, Innovation and Infrastructure
The project is a small example of reliable digital infrastructure: a normalised relational data platform, an open REST API, automated tests, and a cloud-hosted database that anyone with the link can reach. It shows how structured data turns scattered information into something searchable and reusable, which is the same pattern behind real-world information systems.

## Secondary: SDG 4 - Quality Education
The repository is a complete, reproducible learning example of DBMS design (ER modelling, normalisation, SQL, views, triggers, procedures, JSONB), cloud deployment and Git collaboration. Other students can clone it and learn from the schema, scripts and documentation.

## Minor note: SDG 12 - Responsible Consumption
Comparing a free-to-play build with a premium build (damage logs, "best build" function) helps players decide whether spending is worthwhile.

## What to say honestly in the viva
This is a student project with sample data, so the contribution is **skill-building and a reusable open template**, not large-scale impact. Before quoting specific SDG target numbers, verify them on the official UN SDG website (https://sdgs.un.org/goals).
